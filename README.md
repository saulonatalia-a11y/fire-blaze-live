# Fire Blaze Live

Aplicativo Windows para controlar lives do YouTube com visual roxo gamer.

## Primeira versão
- Painel vertical pensado para 1080x1920
- Cards de espectadores, likes e inscritos
- Meta de likes ou inscritos com texto configurável
- Preview de overlay
- Sorteio por palavra-chave do chat
- Participantes únicos e escolha aleatória
- Interface pronta para a próxima etapa: integração real com YouTube e OBS

## Rodar
1. Instale Node.js
2. Abra o terminal nesta pasta
3. Rode `npm install`
4. Rode `npm start`

## Gerar instalador Windows
`npm run dist`

O instalador será criado pela configuração do electron-builder.

> Os números atuais são demonstrativos. A integração com a API do YouTube será adicionada na próxima etapa.
